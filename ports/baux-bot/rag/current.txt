# Roxanne - Debian Fork of RoxieOS
**RoxieOS is FreeBSD based, this is a fork for Debian Development**

This directory contains the complete Debian-based fork of RoxieOS, enhanced with the most successful concepts from both FreeBSD and Debian development paths. The Debian fork excels at accessibility and live system builds, while FreeBSD leads in mesh networking and AI integration. It exists mostly for rapid development of consepts when tools aren't avaliable in FreeBSD (such as access opencode). It is intened to be an "assist" with development only, not as the primary project.

## Core Philosophy: Best of Both Worlds

**Debian Strengths (Preserved Here):**
- Comprehensive accessibility font stack (9 professional fonts)
- Complete live system build with debootstrap
