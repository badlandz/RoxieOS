# baux-welcome - First-Run Setup
**BAUXBSD initial configuration**

**Status**: DEPRECATED - Remove from v0.1

FreeBSD users are more technically aware than typical Linux users. The "You just got Roxanne'd" warnings and hand-holding are unnecessary for a technical audience.

## Recommendation

Delete this package entirely. Let's system speak for itself through functionality and documentation rather than forced welcome messages.

## Alternative Approach

If first-run setup is needed for v0.2, consider:
- Simple configuration wizard in baux-base
- Optional, not forced
- Focus on system configuration rather than warnings

BAUXBSD should be confident and professional from first boot.
